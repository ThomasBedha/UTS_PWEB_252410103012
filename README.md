# Toko Buku Bekas

Aplikasi web sederhana untuk mengelola stok toko buku bekas, dibuat menggunakan Laravel dengan pola MVC dan Blade. Pengguna login dengan username, lalu username tersebut dikirim ke halaman Dashboard dan Profile. Data buku (judul, penulis, kategori, kondisi, harga, stok) disimpan sebagai array di controller dan ditampilkan di halaman Pengelolaan menggunakan @foreach. Tampilan dibuat dengan Tailwind CSS dan tidak memakai database.

## Fitur
- Login dengan username
- Dashboard berisi ringkasan stok buku
- Pengelolaan: daftar buku dalam bentuk tabel
- Profile: menampilkan data pengguna

## Menggunakan
Laravel, Blade, Tailwind CSS
